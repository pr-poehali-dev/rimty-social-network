# 🔐 Инструкция по настройке OAuth для Rimty

Это пошаговое руководство для подключения авторизации через VK, Одноклассники, Яндекс и Steam.

---

## 📋 Общий принцип OAuth

OAuth позволяет пользователям входить через существующие аккаунты без создания нового пароля. Для каждого провайдера нужно:

1. Зарегистрировать приложение
2. Получить **Client ID** и **Client Secret**
3. Указать **Redirect URI** (куда возвращать пользователя после авторизации)
4. Добавить ключи в секреты проекта

---

## 1️⃣ ВКонтакте (VK)

### Шаг 1: Создание приложения
1. Перейди на [dev.vk.com](https://dev.vk.com/)
2. Войди в свой аккаунт VK
3. Нажми **"Мои приложения"** → **"Создать приложение"**
4. Заполни:
   - **Название**: Rimty
   - **Платформа**: Выбери **"Веб-сайт"**
   - **Адрес сайта**: Укажи URL твоего проекта (например, `https://твой-домен.poehali.dev`)
5. Нажми **"Создать"**

### Шаг 2: Настройка приложения
1. В разделе **"Настройки"** найди:
   - **ID приложения** (это твой Client ID)
   - **Защищённый ключ** (это твой Client Secret)
2. В поле **"Authorized redirect URI"** добавь:
   ```
   https://твой-домен.poehali.dev/auth/vk/callback
   ```
3. Сохрани изменения

### Шаг 3: Получение прав доступа
В разделе **"Права доступа"** включи:
- ✅ **email** (для получения email пользователя)
- ✅ **photos** (для доступа к аватару)

### Что запомнить:
```
VK_CLIENT_ID=твой_id_приложения
VK_CLIENT_SECRET=твой_защищённый_ключ
VK_REDIRECT_URI=https://твой-домен.poehali.dev/auth/vk/callback
```

---

## 2️⃣ Одноклассники (OK)

### Шаг 1: Создание приложения
1. Перейди на [ok.ru/dev](https://ok.ru/dev)
2. Войди в свой аккаунт OK
3. Нажми **"Создать приложение"**
4. Заполни:
   - **Название**: Rimty
   - **Тип приложения**: **"Внешнее"**
   - **Платформа**: **"Web"**
   - **Ссылка на приложение**: URL твоего проекта
5. Нажми **"Создать"**

### Шаг 2: Настройка приложения
1. После создания найди:
   - **Application ID** (Client ID)
   - **Public key**
   - **Secret key** (Client Secret)
2. В поле **"Разрешённые redirect_uri"** добавь:
   ```
   https://твой-домен.poehali.dev/auth/ok/callback
   ```

### Шаг 3: Права доступа
Включи права:
- ✅ **VALUABLE_ACCESS** (базовые данные пользователя)
- ✅ **GET_EMAIL** (доступ к email)

### Что запомнить:
```
OK_APP_ID=твой_application_id
OK_PUBLIC_KEY=твой_public_key
OK_SECRET_KEY=твой_secret_key
OK_REDIRECT_URI=https://твой-домен.poehali.dev/auth/ok/callback
```

---

## 3️⃣ Яндекс

### Шаг 1: Создание приложения
1. Перейди на [oauth.yandex.ru](https://oauth.yandex.ru/)
2. Войди в Яндекс аккаунт
3. Нажми **"Зарегистрировать новое приложение"**
4. Заполни:
   - **Название**: Rimty
   - **Платформы**: Выбери **"Веб-сервисы"**
   - **Redirect URI**: 
     ```
     https://твой-домен.poehali.dev/auth/yandex/callback
     ```

### Шаг 2: Права доступа
Отметь нужные права:
- ✅ **login:email** (доступ к email)
- ✅ **login:info** (имя, фамилия, аватар)
- ✅ **login:avatar** (аватар пользователя)

### Шаг 3: Получение ключей
После создания получишь:
- **ID** (Client ID)
- **Пароль** (Client Secret)

### Что запомнить:
```
YANDEX_CLIENT_ID=твой_id
YANDEX_CLIENT_SECRET=твой_пароль
YANDEX_REDIRECT_URI=https://твой-домен.poehali.dev/auth/yandex/callback
```

---

## 4️⃣ Steam

### Шаг 1: Получение Steam Web API Key
1. Перейди на [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey)
2. Войди в свой Steam аккаунт
3. Заполни форму:
   - **Domain Name**: Укажи домен проекта (например, `твой-домен.poehali.dev`)
4. Согласись с условиями и нажми **"Register"**
5. Скопируй полученный **API Key**

### Особенность Steam
Steam использует **OpenID** вместо классического OAuth. Redirect URI для Steam:
```
https://твой-домен.poehali.dev/auth/steam/callback
```

### Что запомнить:
```
STEAM_API_KEY=твой_steam_api_key
STEAM_REDIRECT_URI=https://твой-домен.poehali.dev/auth/steam/callback
```

## 🔧 Добавление секретов в poehali.dev

После получения всех ключей, нужно добавить их в проект:

### Шаг 1: Открой секреты
1. В редакторе poehali.dev нажми на **⚙️ (настройки)**
2. Выбери **"Секреты"** или скажи мне: **"Добавь секреты"**

### Шаг 2: Добавь следующие секреты

**VKontakte:**
```
VK_CLIENT_ID
VK_CLIENT_SECRET
VK_REDIRECT_URI
```

**Odnoklassniki:**
```
OK_APP_ID
OK_PUBLIC_KEY
OK_SECRET_KEY
OK_REDIRECT_URI
```

**Yandex:**
```
YANDEX_CLIENT_ID
YANDEX_CLIENT_SECRET
YANDEX_REDIRECT_URI
```

**Steam:**
```
STEAM_API_KEY
STEAM_REDIRECT_URI
```

**Дополнительно (для безопасности):**
```
JWT_SECRET=любая_длинная_случайная_строка_для_токенов
SESSION_SECRET=ещё_одна_случайная_строка
```

### Генерация секретных строк
Для JWT_SECRET и SESSION_SECRET можешь использовать любую длинную случайную строку (32+ символа). Например:
```bash
# Linux/Mac в терминале:
openssl rand -hex 32

# Или просто придумай что-то вроде:
mySuperSecret_Rimty_2024_RandomString123456789
```

## ⚠️ Важные моменты

### Безопасность
- ❌ **НИКОГДА** не публикуй Client Secret в открытом коде
- ✅ Используй только через секреты proehali.dev
- ✅ Redirect URI должны точно совпадать во всех местах

### Тестирование
- Для локальной разработки используй `http://localhost:5173/auth/*/callback`
- Для продакшена используй реальный домен проекта

### Лимиты API
- **VK**: 3 запроса в секунду
- **OK**: 10000 запросов в день
- **Яндекс**: Без ограничений для OAuth
- **Steam**: 100000 запросов в день

## 🆘 Проблемы?

**Не получается зарегистрировать приложение?**
- Убедись, что у тебя полноценный аккаунт (не временный)
- Некоторые платформы требуют подтверждённый номер телефона

**Redirect URI не работает?**
- Проверь, что URL указан **ТОЧНО** одинаково везде
- Проверь наличие/отсутствие слэша в конце URL

**Ошибка "invalid_client"?**
- Перепроверь Client ID и Client Secret
- Убедись, что секреты добавлены без пробелов и лишних символов
